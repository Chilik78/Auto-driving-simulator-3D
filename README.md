# Auto-driving-simulator-3D

Виртуальный тренажёр для отработки навыков вождения, разработанный в Unity с интеграцией транспортного симулятора SUMO.

---

## О проекте

Приложение воссоздаёт городскую среду с реалистичным дорожным трафиком. Игрок выбирает транспортное средство и отрабатывает навыки вождения: соблюдение ПДД, движение в потоке, реакцию на светофоры. Транспортный поток генерируется и управляется утилитой SUMO в реальном времени через протокол TraCI.

## Требования и установка

### Предварительные требования

1. **Unity 2022.3.4f1** — строго эта версия для совместимости проекта
2. **SUMO 1.17.0 или 1.18.0** — транспортный симулятор
3. **Visual Studio 2022** — для редактирования скриптов

### Запуск проекта

1. Установите SUMO и убедитесь, что переменная окружения `SUMO_HOME` указывает на папку установки (`C:\...\Sumo`).
2. Откройте папку `ADS/` как проект в Unity Hub.
3. Откройте сцену `Assets/Scenes/SampleScene.unity`.
4. В иерархии (`Hierarchy`) выберите объект **MyScripts** → в `Inspector` раскройте компонент **Main Handler** → в поле **Sumo Path** укажите путь до папки SUMO.
5. Нажмите **Play**.

## Геймплей

### Выбор транспорта

В главном меню доступны три транспортных средства:

| Транспорт | Тип |
|-----------|-----|
| Audi10 | Легковой автомобиль |
| Icarus | Автобус |
| ЗИЛ-8 | Грузовик |

### Управление

| Клавиша | Действие |
|---------|----------|
| `Mouse` | Управление камерой |
| `W A S D` | Движение транспорта |
| `Space` | Ручной тормоз |
| `F` | Включить / выключить фары |
| `Q` / `E` | Левый / правый поворотник |
| `V` | Мигалки грузовика (только ЗИЛ) |
| `L` | Включить / выключить уличные фонари |
| `G` | Выйти в меню выбора транспорта |
| `Esc` | Показать курсор мыши |

### Система штрафов

Игрок начинает с **100 очков**. При достижении 0 происходит возврат в главное меню.

| Нарушение | Штраф |
|-----------|-------|
| Езда с выключенными фарами | −5 очков |
| ДТП с участием другого транспорта | −30 очков |

## Устранение неполадок

### Unity зависает при нажатии «Поехали»

**Причина:** не задан путь до SUMO.

**Решение:**
1. Перезапустите проект Unity, не запуская симуляцию.
2. В `Hierarchy` выберите **MyScripts**.
3. В `Inspector` раскройте **Main Handler**.
4. В поле **Sumo Path** введите путь до папки SUMO (например, `C:\Program Files (x86)\Eclipse\Sumo`).
5. Запустите симуляцию.

### Низкий FPS

**Решение:**
1. Нажмите `L` — это отключит уличное освещение и снизит нагрузку на GPU.
2. Если не помогло: остановите симуляцию → откройте **Main Handler** → уменьшите значение **Max Num Veh** (максимальное число машин в симуляции).
